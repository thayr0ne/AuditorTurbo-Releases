# Auditor Turbo — Downloads oficiais

Canal **público e gratuito** de distribuição do Auditor Turbo para Windows.

**Instaladores:** consulte [Releases](https://github.com/thayr0ne/AuditorTurbo-Releases/releases). Até a publicação da primeira versão, não haverá instalador disponível nessa página.

O código-fonte e a compilação são mantidos em repositório separado, privado. **Não envie código-fonte, documentos médicos, dados de beneficiários, credenciais ou bancos de dados para este repositório público.**

## Atualizações no aplicativo

Em **Configurações → Atualizações do aplicativo**, a origem de distribuição é:

`thayr0ne/AuditorTurbo-Releases`

O aplicativo verifica novas versões publicadas como GitHub Releases. Instale apenas versões acompanhadas das notas de versão e do arquivo de verificação SHA-256 correspondente. O verificador de hash não substitui uma assinatura digital de autoria.

## Manutenção

1. Compile e teste o instalador no GitHub privado.
2. Prepare o executável **sem segredos nem dados pessoais**.
3. Gere o SHA-256 do executável efetivamente publicado.
4. Crie uma Release estável neste repositório público, com tag semântica (ex.: `v2.9.1`), notas de versão, EXE e checksum.
5. Teste a consulta e o download pelo Auditor Turbo em um computador limpo.

**Importante:** este repositório público serve somente à distribuição, não à compilação nem ao armazenamento de projetos privados.
